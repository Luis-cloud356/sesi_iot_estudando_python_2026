
# Estudando Python

## Descrição

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- VS Code

## Para testar

No terminal, execute o comando abaixo, substituindo `nome_arquivo.py` pelo nome do arquivo que deseja executar:

```bash
python nome_arquivo.py
```

### Exemplos

```bash
python exercicio01_media.py
python exercicio02_temperatura.py
```
